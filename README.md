# Course-Project

## WatchTower

WatchTower is a web application monitoring tool that captures real user events, errors, performance metrics, and user interactions to provide insights through a real-time dashboard.

### Current Priority
Creating user stories and thinking about the user

### Features (MVP)
- JavaScript error tracking
- Performance metrics monitoring
- User interaction capture
- Real-time dashboard with error feed, latency charts, and active user count
- Event storage and filtering
- Version tracking for errors

### Project Structure
- `docs/` - Documentation, requirements, and planning
- `src/` - Source code, including prototypes
- `tests/` - Test files and documentation
