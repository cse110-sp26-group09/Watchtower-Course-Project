# Archive (`archive/`)

**Status:** Historical. Nothing here is part of the active product.

This directory preserves earlier WatchTower prototypes for project history and
grading. The active product lives under [`../src`](../src) (`backend/`,
`frontend/`, `sdk/`, `shared/`). Do not build new features here.

| Path | What it is |
|---|---|
| `prototype_1/` | Sprint 2 Prototype 1 (static dashboard + early SDK/server experiments). |
| `prototype_2/` | Sprint 2 Prototype 2 (alternate dashboard + vertical slice). |
| `Prototype1/` | An earlier Prototype 1 snapshot kept for history. |

The current product (formerly "Prototype 3") merged the strongest parts of
Prototype 1 and 2; the comparison rubric used to make that call lives in
[`docs/process/prototype-comparison-rubric.md`](../docs/process/prototype-comparison-rubric.md).

> Commands and paths referenced inside these archived folders (e.g.
> `npm run start:prototype1`) are historical and may no longer work against the
> current `package.json`.
