# Sprint Retrospectives

This directory contains retrospective documents for each sprint of the WatchTower project.

## Purpose

Retrospectives help the team reflect on what went well, what didn't, and how to improve in future sprints. They promote continuous improvement and team learning.

## Format

Each retrospective should include:

- **What went well**: Positive aspects and successes
- **What didn't go well**: Challenges and issues encountered
- **Action items**: Specific improvements to implement
- **Lessons learned**: Key takeaways for the team

## Schedule

Retrospectives are conducted at the end of each sprint, typically during the sprint review meeting.
