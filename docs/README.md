# Documentation

This directory contains all project documentation, including requirements, planning, research, and decision records.

## Contents

- `mvp.md` - Minimum Viable Product features and requirements
- `requirements.md` - Detailed functional and non-functional requirements
- `sprint-1-planning.md` - Sprint 1 planning document with tasks and roles
- `adr/` - Architectural Decision Records
- `research/` - Research materials and user stories
- `retrospectives/` - Sprint retrospectives and lessons learned

## How to Contribute

- Keep documentation up-to-date with project changes
- Use clear, concise language
- Follow the project's conventional commit guidelines for documentation changes
