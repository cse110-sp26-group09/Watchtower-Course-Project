The wireframe has 3 main parts:
-The home page
-The analytics page
-The settings page

The home page is the main page where engineers, managers, etc will monitor the status of the software that they are watching

The analytics page is for more long term stuff such as user activity over time

The settings is where a user can enable/disable notifications, get accessibiltiy options, etc.

USER FLOW FOR PROBLEM:
-Get notified (like a google calendar notification with the option to disable notifications)
-Go on watchtower homepage
-See issues with version and assign issues to be taken care of.
