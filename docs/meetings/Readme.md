# Meeting Directory

This is a general directory for documentation of meetings to show off our progress

## Purpose 
Standup notes are important because they provide a quick record of what each team member completed, what they are working on next, and any blockers they are facing. This helps keep everyone aligned, improves accountability, and makes it easier to track progress and address issues before they delay the project.

We also keep a rolling documentation of decision we have made connect to our github issues
