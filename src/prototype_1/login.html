Privacy Policy

WatchTower is a student project prototype for monitoring web app errors, performance, and user feedback. This login screen is for demonstration only and should not be used with real passwords.

  • Demo sign-in state is stored locally in the browser for prototype navigation.
  • Google sign-in is a visual prototype action and does not connect to a real Google account.
  • Any event data used by WatchTower should be limited to development, testing, or demo content.
  • The team should review privacy, authentication, and data-handling needs before any production release.

About Us

Team Identity

Akatsuki is a team built on collaboration, discipline, and adaptability. Different people with different strengths come together to create something coordinated, memorable, and worth being proud of.

Team Values

  • Unity through different strengthsWe combine unique skills and perspectives to build better solutions.
